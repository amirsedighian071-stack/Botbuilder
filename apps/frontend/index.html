BotForge 1.0 — آماده استقرار صنعتی

ربات پیام‌رسان خود را بسازید، خودکار مستقر کنید و از یک داشبورد مدیریت کنید.

زیرساخت کامل Node.js و Cloudflare Workers با موتور مشترک تلگرام، بله و روبیکا، ۳۲ قالب ربات آماده، اعتبارسنجی زنده توکن، ساخت خودکار پایگاه‌داده، اتصال وب‌هوک و بررسی سلامت. هیچ بخشی از این پروژه شبیه‌سازی نیست؛ همه مسیرها کد اجرایی واقعی دارند.

معماری

هر چیزی که یک ربات تجاری لازم دارد، بدون بخش ناتمام

BotForge یک مونوریپوی TypeScript است: هسته مشترک، آداپتور پلتفرم‌ها، موتور اجرا، ۳۲ قالب ربات، سرویس تک‌ربات install و ورکر Cloudflare. ویزارد همین سایت، بسته استقرار را در مرورگر می‌سازد و هر ماژول تست و اعتبارسنجی دارد.

موتور مشترک چندپلتفرمه

یک هسته برای تلگرام، بله و روبیکا؛ تفاوت‌ها در لایه آداپتور جدا شده‌اند تا منطق ربات یک بار نوشته و روی هر سه پلتفرم اجرا شود.

استقرار خودکار با API

با وارد کردن توکن میزبان، سرور پایگاه‌داده را می‌سازد، بسته را بارگذاری می‌کند، متغیرهای محیطی را تزریق و وب‌هوک را ثبت می‌کند؛ سپس سلامت سرویس را می‌سنجد.

عضویت اجباری و ضدسوءاستفاده

بررسی عضویت در کانال‌ها، مسدودسازی کاربران، محدودیت نرخ روی وب‌هوک و ارسال همگانی، محافظت SSRF و اعتبارسنجی سخت‌گیرانه ورودی‌ها.

داشبورد مدیریت واقعی

آمار زنده کاربران و پیام‌ها، مدیریت نقش‌ها، مسدودسازی، ارسال همگانی با نرخ مجاز، حالت تعمیر و مشاهده رویدادها برای هر ربات به‌صورت جداگانه.

سه موتور ذخیره‌سازی

SQLite برای اجرای سریع، PostgreSQL برای تولید و D1 برای ورکر؛ همه پشت یک لایه Storage با جداسازی کامل داده هر ربات.

صف کار و کرون

کارهای پس‌زمینه با تلاش مجدد و زمان‌بندی، اجرای زمان‌بند ورکر هر دقیقه و پیگیری وضعیت کارها در داشبورد و API.

انتخاب ربات و پلتفرم

از میان ۳۲ قالب، ربات مناسب را انتخاب و پلتفرم مقصد را مشخص کنید.

دریافت و بررسی توکن

دکمه «دریافت توکن» شما را به BotFather می‌برد؛ پس از ورود توکن، همان توکن در مرورگر با API رسمی پلتفرم بررسی می‌شود.

کلیدها و میزبان

فقط کلیدهایی که همین ربات لازم دارد پرسیده می‌شود؛ میزبان استقرار را انتخاب می‌کنید و بسته آماده می‌شود.

استقرار و سلامت

فایل ZIP را دانلود و با یک دستور مستقر می‌کنید؛ پایگاه‌داده، رازها و وب‌هوک خودکار ثبت می‌شوند و سلامت را همین سایت بررسی می‌کند.

نکته مهم درباره همین سایت این صفحه روی GitHub Pages میزبانی می‌شود و همه‌چیز در مرورگر شما انجام می‌شود: انتخاب قالب، کلیدها و ساخت بسته ZIP. نه سروری از شما خواسته می‌شود، نه ورود به پنل واسط؛ فقط بسته را دانلود و با یک دستور مستقر می‌کنید.
پرسش‌های پرتکرار

پاسخ‌های کوتاه و دقیق

نه. GitHub Pages فقط فایل‌های ایستا را سرو می‌کند و همان‌جا بسته استقرار ساخته می‌شود. اجرای ربات روی حساب Cloudflare (ورکر + D1) یا Railway (Docker + PostgreSQL) خودتان انجام می‌شود؛ پیکربندی هر دو در بسته ZIP آماده است.
توکن ربات و اعتبارنامه میزبان فقط در حافظه و sessionStorage همان تب نگه داشته می‌شوند و با بستن تب پاک می‌شوند. در سرور، اعتبارنامه‌ها با کلید اصلی رمزنگاری و ذخیره می‌شوند و در پاسخ API هرگز بازگردانده نمی‌شوند.
برای جلوگیری از کپی ناخواسته محتوا، متن‌ها غیرقابل انتخاب هستند؛ اما توکن‌ها، کلیدها، قطعه‌کدها و فرمان‌ها قابل انتخاب‌اند و دکمه «کپی در حافظه» دارند.
بله؛ ویزارد به توکن میزبان نیازی ندارد. فایل .env، اسکریپت deploy.sh و پیکربندی هر دو میزبان در بسته ZIP هست و همان مراحل را دستی اجرا می‌کنید.
نه. هر ربات شناسه مستقل، توکن رمزنگاری‌شده، تنظیمات، کاربران و رویدادهای جدا دارد. تمام پرس‌وجوهای ذخیره‌سازی با شناسه ربات محدود شده‌اند.
