مسیر واقعی استقرار

  1. اعتبارسنجی توکن ربات با فراخوانی getMe پلتفرم.
  2. بررسی توکن میزبان با API رسمی Cloudflare یا Railway.
  3. ساخت پایگاه‌داده D1 یا اتصال PostgreSQL و اجرای طرح‌واره.
  4. تزریق متغیرهای محیطی و رمزهای تولیدشده در سمت سرور.
  5. بارگذاری بسته ورکر یا استقرار سرویس Node.js و تخصیص دامنه.
  6. ثبت وب‌هوک با کلید مخفی در پلتفرم پیام‌رسان.
  7. درخواست /health و ثبت نتیجه در تاریخچه.

اگر API در دسترس نباشد

GitHub Pages نمی‌تواند کد سمت سرور اجرا کند. در این حالت ویزارد یک بسته واقعی می‌سازد: فایل .env، نقشه استقرار JSON و اسکریپت bash که همان دو درخواست API را با curl اجرا می‌کند. برای اعتبارسنجی زنده، کنترل‌پلین را با docker compose up یا Railway راه‌اندازی کنید.

راهنمای کامل استقرار رفتن به ویزارد
توکن میزبان همان دسترسی GitHub نیست توکن Railway یا Cloudflare فقط برای ساخت سرویس و متغیرها استفاده می‌شود. برای استقرار از مخزن GitHub روی Railway، باید مخزن را یک بار در حساب Railway متصل کنید؛ این کار از مرورگر و با API توکن انجام نمی‌شود.
