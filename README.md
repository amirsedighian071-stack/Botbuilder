# BotForge

پلتفرم متن‌باز ساخت، استقرار و مدیریت ربات‌های پیام‌رسان برای **تلگرام**، **بله** و **روبیکا** با ۳۲ ربات تولیدی، موتور مشترک، آداپترهای مستقل و ویزارد سازنده بسته استقرار.

> این مخزن شامل کد کامل و اجراشدنی است: هیچ ماک، اسکلت خالی یا بخش ناتمامی وجود ندارد. سایت استاتیک، API، پایگاه داده، صف کار، پنل مدیریت و منطق هر ۳۲ ربات پیاده‌سازی شده‌اند.

## ویژگی‌ها

- **موتور مشترک ربات**: منو، وضعیت گفتگو (FSM)، دکمه‌های شیشه‌ای، تنظیمات لایه‌ای، آمار، مدیریت خطا و محدودیت نرخ به‌ازای کاربر.
- **سه آداپتر مستقل**: Telegram، Bale و Rubika با نگاشت پیام، دکمه، فایل، ویدئو، حذف پیام و بررسی عضویت.
- **۳۲ قالب ربات**: از قیمت طلا و فروشگاه تا دانلودر، هوش مصنوعی، مدیریت گروه، فرم‌ساز و پایش سایت.
- **سرویس تک‌ربات (`dist/install/main.js`)**: همه‌چیز از متغیرهای محیطی خوانده می‌شود؛ احراز هویت مدیر با JWT، مدیریت کاربر/تنظیمات/سند، پیام همگانی صف‌محور و سرو رسانه امضاشده.
- **ویزارد سازنده بسته در مرورگر**: انتخاب قالب، پلتفرم، کلیدها و میزبان، سپس تولید ZIP کامل شامل `.env`، `deploy.sh`، `wrangler.toml` یا `Dockerfile` و آدرس وب‌هوک؛ بدون سرور واسط و بدون ورود به پنل.
- **پایگاه داده چندگانه**: PostgreSQL برای تولید، SQLite برای تک‌سرور و Cloudflare D1 برای ورکر، با جداسازی کامل داده هر ربات.
- **صف کار پایدار**: تلاش مجدد نمایی، سقف تلاش، زمان‌بندی و اجرای دوره‌ای در Node.js یا cron ورکر.
- **امنیت تولیدی**: AES-256-GCM برای توکن‌ها، امضای وب‌هوک، محافظت SSRF، اعتبارسنجی Zod، هدرهای امنیتی و محدودیت نرخ چندلایه.
- **سایت GitHub Pages**: کاتالوگ تعاملی، ویزارد چهارمرحله‌ای، داشبورد نصب‌ها، صفحه استقرار، کنسول مدیریت ربات و مستندات کامل؛ رابط راست‌به‌چپ، بدون ایموجی و با دکمه کپی برای داده‌های مهم.

## شروع سریع

برای استفاده از سایت هیچ سروری لازم نیست؛ کافی است خروجی ایستا را سرو کنید:

```bash
git clone https://github.com/amirsedighian071-stack/Botbuilder.git
cd Botbuilder
npm install
npm run build                                   # dist/install/main.js و بسته ورکر
node scripts/serve-frontend.mjs --port 4173     # http://127.0.0.1:4173
```

اجرای محلی سرویس تک‌ربات (همان چیزی که بسته استقرار اجرا می‌کند):

```bash
BOT_TEMPLATE=gold-price BOT_PLATFORM=telegram BOT_TOKEN="123456:AA..." \
BOT_SLUG=gold-price BOT_NAME="قیمت طلا" \
SECRET_MASTER_KEY="$(node -e "console.log(require('crypto').randomBytes(32).toString('hex'))")" \
JWT_SECRET="$(node -e "console.log(require('crypto').randomBytes(32).toString('hex'))")" \
ADMIN_SEED_EMAIL=admin@example.com ADMIN_SEED_PASSWORD='ChangeMe#2026' \
DATABASE_DRIVER=sqlite PORT=8080 node dist/install/main.js
```

## ساختار مخزن

```
apps/
  control-plane/        API، وب‌هوک، رسانه، صف و سرویس install (تک‌ربات)، Dockerfile
  frontend/             سایت چندصفحه‌ای GitHub Pages + ویزارد سازنده بسته در مرورگر
  cloudflare-worker/    ورکر وب‌هوک روی D1 + cron
packages/
  core/                 تایپ‌ها، رمزنگاری، اعتبارسنجی، SSRF، ذخیره‌سازی
  platform-adapters/    آداپتر تلگرام، بله، روبیکا
  engine/               زمان اجرای ربات، صف، پنل مدیریت، نصب‌کننده تک‌ربات
  bot-templates/        ۳۲ قالب ربات + kit مشترک
scripts/                build، تولید کاتالوگ، سرو محلی (`dist/install/main.js` هم از همین‌جا ساخته می‌شود)
```

## دسته‌بندی ربات‌ها

| دسته | عنوان | ربات‌ها |
| --- | --- | --- |
| A | مالی و اطلاعاتی | قیمت طلا و ارز، اخبار، هشدار قیمت، آب‌وهوا، ماشین‌حساب مالی |
| B | فروش و کسب‌وکار | فروشگاه، پشتیبانی، نوبت‌دهی، اشتراک، بازاریابی، سفارش خدمات، CRM |
| C | دانلود و رسانه | اینستاگرام، یوتیوب، موسیقی به ویس، ویس به موسیقی، مدیریت فایل، تبدیل فرمت، گفتار به متن، متن به گفتار |
| D | هوش مصنوعی | دستیار، مترجم، دستیار مطالعه، تولید محتوا، خلاصه‌ساز لینک |
| E | مدیریت و ابزار | مدیریت گروه، نظرسنجی و آزمون، یادآور، کوتاه‌کننده لینک، فرم‌ساز، دوره آموزشی، پایش سایت |

فهرست کامل با دستورها و کلیدهای لازم در `apps/frontend/docs.html#bots` یا مسیر `GET /api/catalog` موجود است.

## استقرار

هیچ استقرار خودکاری به سرور واسط وابسته نیست؛ ویزارد بسته را می‌سازد و شما یک دستور اجرا می‌کنید:

1. در [ویزارد](apps/frontend/wizard.html) قالب، پلتفرم، توکن ربات، کلیدهای یکپارچه‌سازی و میزبان را انتخاب کنید.
2. ZIP بسته را دانلود و از حالت فشرده خارج کنید.
3. `bash deploy.sh` را با توکن میزبان اجرا کنید.

| میزبان | کاری که `deploy.sh` انجام می‌دهد |
| --- | --- |
| Cloudflare Workers + D1 | `wrangler d1 create`، اجرای `schema.sql` و `bot-row.sql`، ثبت secretها، `wrangler deploy` و `setWebhook` |
| Railway / Docker | ساخت پروژه، تنظیم همه متغیرهای `.env`، گرفتن دامنه و استقرار ایمیج `dist/install/main.js` با ffmpeg |

راهنمای گام‌به‌گام با دستورهای کامل در [`docs/AUTO-DEPLOY.md`](docs/AUTO-DEPLOY.md) است.

### سایت چندصفحه‌ای

| مسیر | محتوا |
| --- | --- |
| `index.html` | معرفی، معماری، دسته‌ها، میزبان‌ها و پرسش‌های پرتکرار |
| `catalog.html` | کاتالوگ ۳۲ ربات با جست‌وجو، فیلتر و نمای کارت/جدول |
| `wizard.html` | ویزارد چهارمرحله‌ای ساخت بسته: قالب ← پلتفرم و توکن ← کلیدها ← ساخت و استقرار |
| `dashboard.html` | نصب‌های ساخته‌شده در همین مرورگر: وضعیت، بررسی سلامت، دانلود دوباره بسته و حذف |
| `deployment.html` | دامنه سرویس، آدرس وب‌هوک، بررسی واقعی سلامت و مراحل استقرار مخصوص هر میزبان |
| `admin/index.html` | کنسول مدیریت ربات مستقرشده: آمار، کاربران، مسدودسازی، پیام همگانی، عضویت اجباری، مدیران، کلیدهای API، صف کار و حسابرسی |
| `docs.html` | مستندات کامل شامل قرارداد متغیرها، بسته استقرار، امنیت و عیب‌یابی |

سایت هیچ فریم‌ورک CSS یا CDN خارجی بارگذاری نمی‌کند؛ استایل‌ها در `apps/frontend/assets/css/main.css` و اسکریپت‌ها در
`apps/frontend/assets/js/` هستند تا روی GitHub Pages و پیش‌نمایش محلی یکسان کار کنند.

### بدون سرور، کامل

- ویزارد توکن یا کلید را به هیچ سروری نمی‌فرستد؛ همه پردازش‌ها در همان تب مرورگر انجام و فقط در فایل ZIP ذخیره
  می‌شوند.
- اعتبارسنجی زنده پلتفرم اختیاری است: اگر مرورگر به API پلتفرم دسترسی نداشته باشد، الگوی توکن بررسی و ادامه داده
  می‌شود.
- پردازش رسانه و ffmpeg روی Cloudflare Workers پشتیبانی نمی‌شود؛ برای ربات‌های دسته C از Railway استفاده کنید.
- `PUBLIC_BASE_URL` را پس از گرفتن دامنه نهایی تنظیم و استقرار را دوباره اجرا کنید تا آدرس وب‌هوک درست ثبت شود.

## امنیت

- توکن ربات با AES-256-GCM ذخیره و فقط ماسک‌شده نمایش داده می‌شود.
- وب‌هوک شامل secret یکتا و بررسی هدر اختصاصی تلگرام است.
- همه ورودی‌ها با Zod اعتبارسنجی و همه کوئری‌ها پارامتری اجرا می‌شوند.
- درخواست‌های خارجی از فیلتر SSRF (شبکه خصوصی، متادیتای ابری، پورت غیرمجاز) عبور می‌کنند.
- پیام همگانی با باکت توکنی و سقف پیکربندی‌شده ارسال می‌شود.
