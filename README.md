# BotForge

پلتفرم متن‌باز ساخت، استقرار و مدیریت ربات‌های پیام‌رسان برای **تلگرام**، **بله** و **روبیکا** با ۳۲ ربات تولیدی، موتور مشترک، آداپترهای مستقل و کنترل‌پلین مدیریتی.

> این مخزن شامل کد کامل و اجراشدنی است: هیچ ماک، اسکلت خالی یا بخش ناتمامی وجود ندارد. سایت استاتیک، API، پایگاه داده، صف کار، پنل مدیریت و منطق هر ۳۲ ربات پیاده‌سازی شده‌اند.

## ویژگی‌ها

- **موتور مشترک ربات**: منو، وضعیت گفتگو (FSM)، دکمه‌های شیشه‌ای، تنظیمات لایه‌ای، آمار، مدیریت خطا و محدودیت نرخ به‌ازای کاربر.
- **سه آداپتر مستقل**: Telegram، Bale و Rubika با نگاشت پیام، دکمه، فایل، ویدئو، حذف پیام و بررسی عضویت.
- **۳۲ قالب ربات**: از قیمت طلا و فروشگاه تا دانلودر، هوش مصنوعی، مدیریت گروه، فرم‌ساز و پایش سایت.
- **کنترل‌پلین Fastify**: احراز هویت مدیر با JWT، کلید API با دامنه دسترسی، مدیریت ربات/کاربر/تنظیمات/سند، پیام همگانی صف‌محور و سرو رسانه امضاشده.
- **پایگاه داده چندگانه**: PostgreSQL برای تولید، SQLite برای تک‌سرور و Cloudflare D1 برای ورکر، با جداسازی کامل داده هر ربات.
- **صف کار پایدار**: تلاش مجدد نمایی، سقف تلاش، زمان‌بندی و اجرای دوره‌ای در Node.js یا cron ورکر.
- **امنیت تولیدی**: AES-256-GCM برای توکن‌ها، امضای وب‌هوک، محافظت SSRF، اعتبارسنجی Zod، هدرهای امنیتی و محدودیت نرخ چندلایه.
- **سایت GitHub Pages**: کاتالوگ تعاملی، ویزارد چهارمرحله‌ای، مستندات کامل، رابط راست‌به‌چپ، بدون ایموجی و با دکمه کپی برای داده‌های مهم.

## شروع سریع

پیش‌نیاز: Node.js ۲۰.۱۱ یا بالاتر، npm ۱۰ و (اختیاری) ffmpeg برای ربات‌های رسانه.

```bash
git clone https://github.com/amirsedighian071-stack/Botbuilder.git
cd Botbuilder
npm install

cp .env.example .env
# SECRET_MASTER_KEY و JWT_SECRET را با مقدار تصادفی جایگزین کنید:
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

npm run migrate
npm run seed
npm run dev:api      # http://localhost:8080/health
npm run dev:web      # http://localhost:4173
```

## ساختار مخزن

```
apps/
  control-plane/        API مدیریت، وب‌هوک، رسانه، راه‌اندازی صف، Dockerfile
  frontend/             سایت استاتیک GitHub Pages (کاتالوگ، ویزارد، مستندات)
  cloudflare-worker/    ورکر وب‌هوک روی D1 + cron
packages/
  core/                 تایپ‌ها، رمزنگاری، اعتبارسنجی، SSRF، ذخیره‌سازی
  platform-adapters/    آداپتر تلگرام، بله، روبیکا
  engine/               زمان اجرای ربات، صف، پنل مدیریت، سرویس‌ها
  bot-templates/        ۳۲ قالب ربات + kit مشترک
scripts/                build، تولید کاتالوگ، سرو محلی، خروجی اسکیما
```

## دسته‌بندی ربات‌ها

| دسته | عنوان | ربات‌ها |
| --- | --- | --- |
| A | مالی و اطلاعاتی | قیمت طلا و ارز، اخبار، هشدار قیمت، آب‌وهوا، ماشین‌حساب مالی |
| B | فروش و کسب‌وکار | فروشگاه، پشتیبانی، نوبت‌دهی، اشتراک، بازاریابی، سفارش خدمات، CRM |
| C | دانلود و رسانه | اینستاگرام، یوتیوب، موسیقی به ویس، ویس به موسیقی، مدیریت فایل، تبدیل فرمت، گفتار به متن، متن به گفتار |
| D | هوش مصنوعی | دستیار، مترجم، دستیار مطالعه، تولید محتوا، خلاصه‌ساز لینک |
| E | مدیریت و ابزار | مدیریت گروه، نظرسنجی و آزمون، یادآور، کوتاه‌کننده لینک، فرم‌ساز، دوره آموزشی، پایش سایت |

فهرست کامل با دستورها و کلیدهای لازم در `apps/frontend/docs.html#bots` یا مسیر `GET /api/catalog` موجود است.

## استقرار

- **Railway**: فایل `railway.json` و ایمیج `apps/control-plane/Dockerfile` آماده است.
- **Docker**: `docker build -t botforge/control-plane -f apps/control-plane/Dockerfile .`
- **Cloudflare Workers + D1**: `cd apps/cloudflare-worker && wrangler deploy` (سرویس‌های رسانه‌ای روی Node.js اجرا شوند).
- **GitHub Pages**: ورک‌فلوی `pages.yml` پوشه `apps/frontend` را منتشر می‌کند.

### استقرار خودکار از API

دکمه «تأیید و استقرار خودکار» در ویزارد این مسیر را طی می‌کند:

1. `POST /api/deploy/validate-token` — بررسی زنده توکن تلگرام/بله/روبیکا با `getMe`.
2. `POST /api/deploy/validate-provider` — بررسی توکن Cloudflare (`/accounts`) یا Railway (`me`).
3. `POST /api/bots` — ساخت ربات و رمزنگاری توکن.
4. `POST /api/bots/:id/deploy` — آغاز استقرار ناهمگام (پاسخ `202`).
5. `GET /api/bots/:id/deployments/:id` — پیگیری گام‌ها تا `healthy` یا `failed`.

دسترسی‌های لازم برای توکن Cloudflare: `Workers Scripts:Edit`، `D1:Edit` و `Account Settings:Read`. توکن Railway از
صفحه Account Tokens ساخته می‌شود. راهنمای کامل در [`docs/AUTO-DEPLOY.md`](docs/AUTO-DEPLOY.md) است.

### محدودیت‌های واقعی

- GitHub Pages فقط فایل ایستا سرو می‌کند و کد سمت سرور اجرا نمی‌کند. برای اعتبارسنجی زنده و استقرار خودکار، آدرس
  کنترل‌پلین باید در ویزارد یا داشبورد وارد شود.
- بدون کنترل‌پلین، ویزارد ساخت واقعی نقشه استقرار (JSON)، فایل `.env` و اسکریپت bash را ارائه می‌دهد.
- پردازش رسانه و ffmpeg روی Cloudflare Workers پشتیبانی نمی‌شود؛ برای ربات‌های دسته C از Railway استفاده کنید.
- توکن Railway معادل اتصال مخزن GitHub نیست؛ اتصال مخزن باید یک بار در داشبورد Railway انجام شود.
- توکن‌های واردشده در مرورگر فقط در حافظه و `sessionStorage` همان تب نگه داشته می‌شوند.

## امنیت

- توکن ربات با AES-256-GCM ذخیره و فقط ماسک‌شده نمایش داده می‌شود.
- وب‌هوک شامل secret یکتا و بررسی هدر اختصاصی تلگرام است.
- همه ورودی‌ها با Zod اعتبارسنجی و همه کوئری‌ها پارامتری اجرا می‌شوند.
- درخواست‌های خارجی از فیلتر SSRF (شبکه خصوصی، متادیتای ابری، پورت غیرمجاز) عبور می‌کنند.
- پیام همگانی با باکت توکنی و سقف پیکربندی‌شده ارسال می‌شود.
